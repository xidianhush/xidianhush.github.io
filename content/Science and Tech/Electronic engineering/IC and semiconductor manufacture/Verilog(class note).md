🎯 学习策略 / 小建议

  

  

- 基础打牢：先掌握 Verilog 的基本语法、module、data types、always 块、blocking / nonblocking 赋值、时序建模等，再逐步往复杂组合逻辑 / 时序逻辑 / FSM / memory / testbench 方向扩展。
- 多写、多仿真：每写一个模块就做仿真（用 testbench），观察波形，验证行为是否符合预期。在线工具 + 本地仿真器配合使用很好。
- 读别人的工程 / 核心模块：看开源的 Verilog 项目或工程代码，理解设计风格、接口、时序约束等。
- 了解合成限制：并不是 Verilog 写什么就能合成，了解哪些语句 / 结构是合成友好的，哪些是仿真专用的（比如 initial、$display 等）。
- 渐进升级工具链：从在线工具 -> 开源仿真器 -> 综合工具 -> 工业 EDA 工具，逐步熟悉整个 FPGA/ASIC 的设计流程。

1. 算数运算符

| 运算符 | 作用        | 举例                    |
| --- | --------- | --------------------- |
| +   | 加法运算      | `a = 3 + 5;` 结果为 `8`  |
| -   | 减法运算      | `b = 10 - 4;` 结果为 `6` |
| *   | 乘法运算      | `c = 2 * 6;` 结果为 `12` |
| /   | 除法运算（取商）  | `d = 15 / 4;` 结果为 `3` |
| %   | 取模运算（取余数） | `e = 15 % 4;` 结果为 `3` |

2. 关系运算符

|运算符|作用|举例|
|---|---|---|
|>|判断左边操作数是否大于右边操作数|`3 > 2` 结果为 `1`（真）|
|<|判断左边操作数是否小于右边操作数|`3 < 2` 结果为 `0`（假）|
|>=|判断左边操作数是否大于等于右边操作数|`5 >= 5` 结果为 `1`（真）|
|<=|判断左边操作数是否小于等于右边操作数|`5 <= 3` 结果为 `0`（假）|

3. 相等关系运算符

|运算符|作用|举例|
|---|---|---|
|==|判断两个操作数是否相等（1 位：1 真 0 假；多位：全位相同为真）|`4'b1010 == 4'b1010` 结果为 `1`（真）|
|!=|判断两个操作数是否不相等（1 位：1 真 0 假；多位：不全位相同为真）|`4'b1010 != 4'b1000` 结果为 `1`（真）|
|===|全等判断（包括对 x、z 的判断，完全一致为真）|`3'b1x0 === 3'b1x0` 结果为 `1`（真）|
|!===|非全等判断（包括对 x、z 的判断，不完全一致为真）|`3'b1x0 !=== 3'b1z0` 结果为 `1`（真）|

4. 逻辑运算符

操作数每一位均为0时才是逻辑0

| 运算符 | 作用                         | 举例                                                      |
| --- | -------------------------- | ------------------------------------------------------- |
| &&  | 逻辑与（双目，两边操作数均为逻辑真时结果为真）    | `a=4'b1110`，`b=4'b0000`，`a && b` 结果为 `0`（假）             |
| \|  | 逻辑或（双目，两边操作数至少一个为逻辑真时结果为真） | `a=4'b1110`，`b=4'b0000`，`a \| b` 结果为 `1`（真）             |
| !   | 逻辑非（单目，操作数为逻辑真时结果为假，反之亦然）  | `a=4'b1110`，`!a` 结果为 `0`（假）；`b=4'b0000`，`!b` 结果为 `1`（真） |

5. 按位运算符

| 运算符 | 作用                               | 举例                                 |
| --- | -------------------------------- | ---------------------------------- |
| ~   | 按位取反（单目，对操作数每一位取反）               | `~4'b1010` 结果为 `4'b0101`           |
| &   | 按位与（双目，对应位均为 1 时结果位为 1，否则为 0）    | `4'b1010 & 4'b1100` 结果为 `4'b1000`  |
| \|  | 按位或（双目，对应位至少一个为 1 时结果位为 1，否则为 0） | `4'b1010 \| 4'b1100` 结果为 `4'b1110` |
| ^   | 按位异或（双目，对应位不同时结果位为 1，相同为 0）      | `4'b1010 ^ 4'b1100` 结果为 `4'b0110`  |
| ^~  | 按位同或（双目，对应位相同时结果位为 1，不同为 0）      | `4'b1010 ^~ 4'b1100` 结果为 `4'b1001` |

6. 归约运算符

| 运算符     | 作用                               | 举例                                     | 举例                                 |
| ------- | -------------------------------- | -------------------------------------- | ---------------------------------- |
| &       | 归约与（单目，对操作数所有位进行与运算，结果为 1 位）     | `&4'b1110` 结果为 `0`（1&1&1&0=0）          |                                    |
| \|      | 归约或（单目，对操作数所有位进行或运算，结果为 1 位）     | `\|4'b1110` 结果为 ``1'b1``（1\|1\|1\|0=1） |                                    |
| ^       | 归约异或（单目，对操作数所有位进行异或运算，结果为 1 位）   | `^4'b1110` 结果为 `1'b1`（1^1^1^0=1）       |                                    |
| ~&      | 归约与非（单目，对操作数所有位先与运算再取反，结果为 1 位）  | `~&4'b1110` 结果为 `1`（~(1&1&1&0)=~0=1）   |                                    |
| ~\|     | 归约或非（单目，对操作数所有位先或运算再取反，结果为 1 位）  | `~                                     | 4'b1110`结果为`0`（~(1\|1\|1\|0)=~1=0） |
| ~^ / ^~ | 归约同或（单目，对操作数所有位先异或运算再取反，结果为 1 位） | `~^4'b1110` 结果为 `0`（~(1^1^1^0)=~1=0）   |                                    |


7. 连接和复制运算符

| 运算符  | 作用                         | 举例                                               |
| ---- | -------------------------- | ------------------------------------------------ |
| {}   | 连接运算符（将多个信号或数值按位连接成一个整体信号） | `{2'b10, 3'b111}` 结果为 `5'b10111`                 |

## 3 Verilog HDL 程序设计语句和描述方式

| 对比点     | 数据流建模（Dataflow）         | 行为级建模（Behavioral）               | 结构化建模（Structural）        |
| ------- | ----------------------- | ------------------------------- | ------------------------ |
| 描述抽象层级  | 中等抽象（描述信号之间的==数据传递==关系） | 高抽象（描述行为、算法、时序流程）               | **最低抽象（门级或模块连接）**        |
| 常用语句    | `assign`，各种运算符          | `always`、`initial` + `=` / `<=` | 模块例化：`and`、`or` 或自定义模块实例 |
| 驱动对象    | `wire`                  | `reg`（或 `logic`）                | `wire`（连接模块之间的信号）        |
| 表达的电路类型 | **组合逻辑**为主              | 既可组合也可时序                        | 完全取决于所连接的模块              |
| 更像      | 电路连接/数学表达式              | 程序控制流                           | 真实硬件电路搭建（拼积木）            |
| 设计思路    | “数据如何从输入流向输出”           | “硬件应该怎么动作”                      | “硬件结构由哪些模块组成”            |

总结一下记中赋值语句

| 赋值方式     | 使用场景                   | 行为类型       | 具体特性                   |
| -------- | ---------------------- | ---------- | ---------------------- |
| `=`      | 过程赋值（always、initial 内） | **阻塞赋值**   | 按顺序执行，先完成当前语句再执行下一条    |
| `<=`     | 过程赋值（always、initial 内） | **非阻塞赋值**  | 并行更新，多用于时序逻辑（寄存器）      |
| `assign` | 连续赋值（在 always 之外）      | **硬件连线关系** | 驱动 wire，逻辑实时更新，多用于组合逻辑 |

#### moore时序：序列检测器例子
```verilog
module serial_detector(
    input clk,         // 全局时钟信号
    input reset,       // 复位信号，高电平有效
    input data_in,     // 串行1bit输入数据
    output data_out    // 检测输出，检测到101时为1
);

// 状态定义，使用2位二进制编码
parameter S0 = 2'b00; // 初始状态
parameter S1 = 2'b01; // 已收到1
parameter S2 = 2'b10; // 已收到10
parameter S3 = 2'b11; // 已收到101

reg [1:0] current_state, next_state;

// 1. 时序逻辑：状态寄存器，时钟同步更新状态。这里对应 **状态方程**
always @(posedge clk or posedge reset) begin
    if (reset) 
        current_state <= S0;
    else 
        current_state <= next_state;
end

// 2. 组合逻辑：次态转移逻辑。这里对应 **驱动方程(激励方程)**
//    在硬件里，`next_state` 这根线就是一条接到触发器D端的**纯粹的导线**
always @(*) begin
    case (current_state)
        S0: next_state = data_in ? S1 : S0;
        S1: next_state = data_in ? S1 : S2;
        S2: next_state = data_in ? S3 : S0;
        S3: next_state = data_in ? S1 : S0;
        default: next_state = S0;
    endcase
end

// 3. 组合逻辑：输出逻辑，仅S3状态输出1。这里对应* *输出方程**
assign data_out = (current_state == S3) ? 1'b1 : 1'b0;

endmodule
```

| 步骤      | 物理动作 / 逻辑动作                                       | 对应的 Verilog 代码                                                               | 对应的时序电路方程                                                               |
| ------- | ------------------------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **第一步** | **脑子计算**：根据现在在哪里（现态 QnQn）和看到了什么（输入 XX），算出下一步该去哪。  | **第2段**：`always @(*)` 里的赋值逻辑。  <br>（如：`S2: next_state = data_in ? S3 : S0;`） | **驱动方程**  <br>Yn=G(Xn,Qn)Yn=G(Xn,Qn)                                    |
| **第二步** | **告知腿**：把算出来的“目标地”放在触发器的输入端（D端）。                  | 代码运行完，`next_state` 这条线（导线）上的信号就稳定了。                                          | 硬件上的**组合逻辑连线**                                                          |
| **第三步** | **听哨声行动**：听到时钟上升沿（`posedge clk`）的哨声，把腿迈出去，变成新的状态。 | **第1段**：`current_state <= next_state;`                                       | **状态方程**  <br>Qn+1=H(Yn,Qn)Qn+1=H(Yn,Qn)                                |
| **第四步** | **发出广播**：到了新状态后，根据这个新状态决定输出什么。                    | **第3段**：`assign data_out = ...;`                                             | **输出方程**  <br>Z=F(Qn)Z=F(Qn) （Moore）  <br>或 Z=F(Xn,Qn)Z=F(Xn,Qn) （Mealy |

```verilog
//a simple aircondition control system descripted by Verilog HDL
module aircondition(clk,rst,high,low,heat,cold);
 
input clk,rst,high,low;
output heat,cold;
reg heat,cold;
 
reg [1:0] pr_state,next_state;
 
parameter too_high = 2'b00;
parameter too_low = 2'b01;
parameter well_situated = 2'b10;
always@ (posedge clk or posedge rst)
begin
	if(rst)
		pr_state <= well_situated;
	else
		pr_state <= next_state;
end
always@ (pr_state or high or low) //空调的下一个状态取决于当且状态以及high或low的取值
begin
	next_state = 2'bxx;
	cold = 1'b0; heat = 1'b0;
	case(pr_state)            //空调的下一个状态取决于当且状态以及high或low的取值
		well_situated:  //如果当且状态为well_situated
		begin
			cold = 1'b0; heat = 1'b0;
			if(high == 1'b1)
			begin
				next_state = too_high;
				cold = 1'b1; 
				heat = 1'b0;
			end
			if(low == 1'b1)
			begin
				next_state = too_low;
				cold = 1'b0;
				heat =1'b1;
			end
		end
		
		too_high:         //如果当且状态为too_high
		begin
			cold = 1'b1; 
			heat = 1'b0;
			if(high == 1'b1)
			begin
				next_state = too_high;
				cold = 1'b1;
				heat = 1'b0;
			end
			else
			begin
				next_state = well_situated;
				cold = 1'b0;
				heat = 1'b0;
			end
		end
		
		too_low:                //如果当前状态为too_low
		begin
			cold = 1'b0;
			heat = 1'b1;
			if(low == 1'b1)
			begin
				next_state = too_low;
				cold = 1'b0;
				heat = 1'b1;
			end
			else
			begin
				next_state = well_situated;
```

```verilog
module minterm_F(a, b, c, F);
    input a, b, c;
    output F;
    
    // 生成变量的反码
    wire a_n, b_n, c_n;
    not u1(a_n, a);
    not u2(b_n, b);
    not u3(c_n, c);
    
    // 实现每个最小项（与门）
    wire m1, m2, m3, m6, m7;
    and u4(m1, a_n, b_n, c);   // m1 = a'b'c
    and u5(m2, a_n, b, c_n);   // m2 = a'bc'

    and u7(m6, a, b, c_n);     // m6 = abc'

    // 最小项相或（或门）
```

### 一、语法格式

`timescale <时间单位>/<时间精度>`

- **时间单位（time unit）**：定义模块中时间值的 “基准单位”（比如 `#5` 代表 5 个时间单位）。
- **时间精度（time precision）**：定义仿真时间的 “最小分辨率”（仿真器能识别的最小时间步长，决定时间值的舍入规则）。

### 二、`1us/100ns` 具体解释

|参数|取值|含义|
|---|---|---|
|时间单位|1us|模块中所有未指定单位的时间值，默认以 1 微秒为单位（如 `#2` → 2us）。|
|时间精度|100ns|仿真器的最小时间步长为 100ns（0.1us），所有时间值会按此精度舍入。|

#### 举例说明

```verilog
`timescale 1us/100ns

module test;
  reg clk;
  
  initial begin
    clk = 0;
    #1.23 clk = 1;  // 1.23个时间单位 = 1.23us，按100ns精度舍入为1.2us（1200ns）
    #0.08 clk = 0;  // 0.08us = 80ns，按100ns精度舍入为0.1us（100ns）
  end
endmodule
```

- `#1.23`：1.23us = 1230ns，精度是 100ns，因此舍入为 1200ns（1.2us）；
- `#0.08`：0.08us = 80ns，精度是 100ns，因此舍入为 100ns（0.1us）。
