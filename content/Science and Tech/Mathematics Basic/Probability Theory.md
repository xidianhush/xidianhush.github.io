$$P(H|E) = \frac{\overbrace{P(E|H) \cdot P(H)}^{\text{似然}\quad\text{先验}}}{\underbrace{P(E)}_{\text{全概率/证据}}}$$
思维过程

先验，

我一开始认为 99% 的人会健康，1% 的人会患病。
我有 99% 的概率是健康的，只有 1% 的概率是患病的。

检测之后，证据随机事件坍缩成确定结果

证据如果检测成阳性，那我患病的概率提升到 16.7%。


随机事件证据的坍缩，用来缩小可能性，缩小样本空间


# 贝叶斯公式笔记：癌症筛查例子

## 一、分清随机事件

| 符号 | 含义 |
|------|------|
| H | 随机事件——患癌 |
| ¬H | 随机事件——健康 |
| E | 随机事件——检测阳性 |
| ¬E | 随机事件——检测阴性 |

---

## 二、共用基础(随机事件概率)：先验 + 似然

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **先验** | $P(H)$ | $0.01$ | 人群中患病率 1% |
| | $P(\neg H)$ | $0.99$ | 健康概率 99% |
| **似然（证据强度）** | $P(E\|H)$ | $0.99$ | 真阳性率：患癌者被检出的概率 |
| | $P(\neg E\|H)$ | $0.01$ | 假阴性率：患癌者被漏检的概率 |
| | $P(E\|\neg H)$ | $0.05$ | 假阳性率：健康者被误报的概率 |
| | $P(\neg E\|\neg H)$ | $0.95$ | 真阴性率：健康者被正确判阴的概率 |

> 似然的特点：**每行加起来等于 1**（已知真相时，所有可能的观测结果概率之和为 1）。

---

## 三、分支 A：检测阳性 → 样本空间坍缩到 E

| 概念                     | 数学表达式                                                    | 具体数值                                         | 含义               |
| ---------------------- | -------------------------------------------------------- | -------------------------------------------- | ---------------- |
| **全概率（证据：随机事件E 坍缩成阳）** | $P(E)=P(E\|H)P(H)+P(E\|\neg H)P(\neg H)$                 | $0.99\times0.01+0.05\times0.99=0.0594$       | 所有人中检测阳性的总比例     |
| **后验（坍缩后缩小样本空间）**      | $P(H\|E)=\dfrac{P(E\|H)\cdot P(H)}{P(E)}$                | $\dfrac{0.99\times0.01}{0.0594}\approx0.167$ | 阳性后真实患癌概率 16.7%  |
|                        | $P(\neg H\|E)=\dfrac{P(E\|\neg H)\cdot P(\neg H)}{P(E)}$ | $\dfrac{0.05\times0.99}{0.0594}\approx0.833$ | 阳性后实际健康的概率 83.3% |

> **验证**：$P(H\|E) + P(\neg H\|E) = 16.7\% + 83.3\% = 100\%$ ✓
> 
> **直觉**：阳性人群里，真患病的只有 0.99%，被误报的健康人有 4.95%，所以大部分阳性其实是假阳性。

---

## 四、分支 B：检测阴性 → 样本空间坍缩到 ¬E

| 概念                      | 数学表达式                                                                   | 具体数值                                           | 含义                   |
| ----------------------- | ----------------------------------------------------------------------- | ---------------------------------------------- | -------------------- |
| **全概率（证据：随机事件¬E 坍缩成阴）** | $P(\neg E)=P(\neg E\|H)P(H)+P(\neg E\|\neg H)P(\neg H)$                 | $0.01\times0.01+0.95\times0.99=0.9406$         | 所有人中检测阴性的总比例         |
| **后验（坍缩后缩小样本空间）**       | $P(H\|\neg E)=\dfrac{P(\neg E\|H)\cdot P(H)}{P(\neg E)}$                | $\dfrac{0.01\times0.01}{0.9406}\approx0.00011$ | 阴性后患癌（漏检）概率 ≈ 0.011% |
|                         | $P(\neg H\|\neg E)=\dfrac{P(\neg E\|\neg H)\cdot P(\neg H)}{P(\neg E)}$ | $\dfrac{0.95\times0.99}{0.9406}\approx0.9999$  | 阴性后真实健康概率 ≈ 99.99%   |

> **验证**：$P(H\|\neg E) + P(\neg H\|\neg E) \approx 0.011\% + 99.99\% \approx 100\%$ ✓
> 
> **直觉**：阴性结果非常可靠——10000 个阴性里只有约 1 个是漏检的。这就是为什么"阴性基本可以放心"。

---

## 五、后验概率全景汇总

| | 检测阳性 E | 检测阴性 ¬E |
|------|:-----------:|:------------:|
| **患癌 H** | $P(H\|E) \approx 16.7\%$ | $P(H\|\neg E) \approx 0.011\%$ |
| **健康 ¬H** | $P(\neg H\|E) \approx 83.3\%$ | $P(\neg H\|\neg E) \approx 99.99\%$ |
| **列合计** | 100% | 100% |

---

## 六、一句话总结

> **同一个先验，遇到不同的证据，坍缩到不同的样本空间，得到不同的后验。**
> 
> 阳性 → 样本空间缩小到 5.94% 的人 → 里面约 1/6 真患病
> 
> 阴性 → 样本空间缩小到 94.06% 的人 → 里面几乎全是健康人

# 贝叶斯公式笔记：三门问题

## 一、事件定义

| 符号 | 含义 |
|------|------|
| H₁ | 随机事件——汽车在 1 号门（你最初选的门） |
| H₂ | 随机事件——汽车在 2 号门 |
| H₃ | 随机事件——汽车在 3 号门 |
| E | 随机事件——主持人打开 3 号门，露出山羊 |

---

## 二、共用基础：先验 + 似然

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **先验** | $P(H_1)$ | $\dfrac{1}{3}$ | 初始时车在 1 号门的概率 |
| | $P(H_2)$ | $\dfrac{1}{3}$ | 初始时车在 2 号门的概率 |
| | $P(H_3)$ | $\dfrac{1}{3}$ | 初始时车在 3 号门的概率 |
| **似然（证据强度）** | $P(E\|H_1)$ | $\dfrac{1}{2}$ | 车在 1 号，主持人随机开 2 或 3 号，开 3 号的概率 |
| | $P(E\|H_2)$ | $1$ | 车在 2 号，主持人只能开 3 号，开 3 号的概率为 1 |
| | $P(E\|H_3)$ | $0$ | 车在 3 号，主持人不能开 3 号，概率为 0 |

> 似然的特点：**每行加起来等于 1**（已知车的位置时，主持人所有可能开门方式的概率之和为 1）。

---

## 三、分支：主持人打开 3 号门 → 样本空间坍缩到 E

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **全概率（证据：E 坍缩成"开 3 号门"）** | $P(E)=P(E\|H_1)P(H_1)+P(E\|H_2)P(H_2)+P(E\|H_3)P(H_3)$ | $\dfrac{1}{2}\times\dfrac{1}{3}+1\times\dfrac{1}{3}+0\times\dfrac{1}{3}=\dfrac{1}{2}$ | 主持人打开 3 号门的总概率 |
| **后验（坍缩后缩小样本空间）** | $P(H_1\|E)=\dfrac{P(E\|H_1)\cdot P(H_1)}{P(E)}$ | $\dfrac{\frac{1}{2}\times\frac{1}{3}}{\frac{1}{2}}=\dfrac{1}{3}$ | 开 3 号门后，车在 1 号门（坚持不换）的概率 1/3 |
| | $P(H_2\|E)=\dfrac{P(E\|H_2)\cdot P(H_2)}{P(E)}$ | $\dfrac{1\times\frac{1}{3}}{\frac{1}{2}}=\dfrac{2}{3}$ | 开 3 号门后，车在 2 号门（换门）的概率 2/3 |
| | $P(H_3\|E)=\dfrac{P(E\|H_3)\cdot P(H_3)}{P(E)}$ | $\dfrac{0\times\frac{1}{3}}{\frac{1}{2}}=0$ | 开 3 号门后，车在 3 号门的概率 0（已排除） |

> **验证**：$P(H_1\|E) + P(H_2\|E) + P(H_3\|E) = \dfrac{1}{3} + \dfrac{2}{3} + 0 = 1$ ✓
> 
> **直觉**：主持人不是随机开门，他的行为携带了信息。车在 2 号门时他"必须"开 3 号，而车在 1 号门时他只是"碰巧"开了 3 号——这两种情况的"力度"不一样，所以后验概率不相等。

---

## 四、后验概率全景汇总

| | 主持人开 3 号门 E |
|------|:-----------:|
| **车在 1 号门 H₁** | $P(H_1\|E) = \dfrac{1}{3}$ |
| **车在 2 号门 H₂** | $P(H_2\|E) = \dfrac{2}{3}$ |
| **车在 3 号门 H₃** | $P(H_3\|E) = 0$ |
| **合计** | 100% |

---

## 五、一句话总结

> **主持人的选择不是随机的，他避开哪扇门，哪扇门的概率就上升。**
> 
> 初始三扇门各 1/3 → 主持人开了 3 号 → 3 号概率归零 → 那 1/3 的概率"流"到了 2 号门 → 2 号门变成 2/3

# 贝叶斯公式笔记：垃圾邮件过滤

## 一、事件定义

| 符号 | 含义 |
|------|------|
| H | 随机事件——邮件是垃圾邮件 |
| ¬H | 随机事件——邮件是正常邮件 |
| E | 随机事件——邮件包含词语"中奖" |
| ¬E | 随机事件——邮件不包含词语"中奖" |

---

## 二、共用基础：先验 + 似然

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **先验** | $P(H)$ | $0.30$ | 邮箱中垃圾邮件占比 30% |
| | $P(\neg H)$ | $0.70$ | 正常邮件占比 70% |
| **似然（证据强度）** | $P(E\|H)$ | $0.50$ | 垃圾邮件里出现"中奖"的概率 |
| | $P(\neg E\|H)$ | $0.50$ | 垃圾邮件里不出现"中奖"的概率 |
| | $P(E\|\neg H)$ | $0.01$ | 正常邮件里出现"中奖"的概率 |
| | $P(\neg E\|\neg H)$ | $0.99$ | 正常邮件里不出现"中奖"的概率 |

> 似然的特点：**每行加起来等于 1**（已知邮件类型时，出现/不出现某词的概率之和为 1）。

---

## 三、分支 A：邮件含"中奖" → 样本空间坍缩到 E

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **全概率（证据：E 坍缩成"含中奖"）** | $P(E)=P(E\|H)P(H)+P(E\|\neg H)P(\neg H)$ | $0.50\times0.30+0.01\times0.70=0.157$ | 所有邮件中包含"中奖"的总比例 |
| **后验（坍缩后缩小样本空间）** | $P(H\|E)=\dfrac{P(E\|H)\cdot P(H)}{P(E)}$ | $\dfrac{0.50\times0.30}{0.157}\approx0.955$ | 含"中奖"的邮件是垃圾的概率 ≈ 95.5% |
| | $P(\neg H\|E)=\dfrac{P(E\|\neg H)\cdot P(\neg H)}{P(E)}$ | $\dfrac{0.01\times0.70}{0.157}\approx0.045$ | 含"中奖"的邮件是正常的概率 ≈ 4.5% |

> **验证**：$P(H\|E) + P(\neg H\|E) \approx 95.5\% + 4.5\% = 100\%$ ✓
> 
> **直觉**："中奖"这个词在垃圾邮件里出现的概率是正常邮件的 50 倍，区分度极强——只要看到这个词，邮件大概率就是垃圾。

---

## 四、分支 B：邮件不含"中奖" → 样本空间坍缩到 ¬E

| 概念 | 数学表达式 | 具体数值 | 含义 |
|------|-----------|---------|------|
| **全概率（证据：¬E 坍缩成"不含中奖"）** | $P(\neg E)=P(\neg E\|H)P(H)+P(\neg E\|\neg H)P(\neg H)$ | $0.50\times0.30+0.99\times0.70=0.843$ | 所有邮件中不含"中奖"的总比例 |
| **后验（坍缩后缩小样本空间）** | $P(H\|\neg E)=\dfrac{P(\neg E\|H)\cdot P(H)}{P(\neg E)}$ | $\dfrac{0.50\times0.30}{0.843}\approx0.178$ | 不含"中奖"的邮件是垃圾的概率 ≈ 17.8% |
| | $P(\neg H\|\neg E)=\dfrac{P(\neg E\|\neg H)\cdot P(\neg H)}{P(\neg E)}$ | $\dfrac{0.99\times0.70}{0.843}\approx0.822$ | 不含"中奖"的邮件是正常的概率 ≈ 82.2% |

> **验证**：$P(H\|\neg E) + P(\neg H\|\neg E) \approx 17.8\% + 82.2\% = 100\%$ ✓
> 
> **直觉**：不含"中奖"并不能完全排除垃圾邮件——因为还有一半垃圾邮件不用这个词。但概率从 30% 降到了 17.8%，确实降低了一些。

---

## 五、后验概率全景汇总

| | 含"中奖" E | 不含"中奖" ¬E |
|------|:-----------:|:------------:|
| **垃圾邮件 H** | $P(H\|E) \approx 95.5\%$ | $P(H\|\neg E) \approx 17.8\%$ |
| **正常邮件 ¬H** | $P(\neg H\|E) \approx 4.5\%$ | $P(\neg H\|\neg E) \approx 82.2\%$ |
| **列合计** | 100% | 100% |

---

## 六、一句话总结

> **一个区分度强的特征，能让概率发生剧烈偏移。**
> 
> 含"中奖" → 从 30% 飙升到 95.5% → 几乎可以判定为垃圾
> 
> 不含"中奖" → 从 30% 降到 17.8% → 降低了但还不能完全放心
> 
> （现实中的垃圾过滤器会结合几十个甚至上百个词，连续做贝叶斯更新，最终概率逼近 0 或 1）
