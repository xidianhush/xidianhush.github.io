

# 局域网与广域网及相关技术总结

## 局域网Local Area Network（LAN）

### 定义

局限于较小地理区域，由多台计算机互联而成，一般覆盖范围在几千米以内。

### 特点

- **覆盖范围小**：如办公室、家庭、校园局部区域。

- **传输速率高**：通常可达 10Mbps - 10Gbps 甚至更高。

- **误码率低**：数据传输可靠性较高。

- **成本相对低**：设备及部署成本不高。

### 常用技术

- **以太网**：局域网主流技术，分有线和无线（Wi-Fi 基于以太网扩展）。通过网线或无线信号连接设备，传输速率多样。

- **Wi-Fi**：基于 IEEE 802.11 标准的无线接入技术，广泛应用于各类场所，方便移动设备联网。

## 广域网Wide Area Network（WAN）

### 定义

覆盖范围极大，能跨越城市、国家乃至全球，用于连接不同地区的网络。

### 特点

- **覆盖范围广**：连接远距离的网络节点。

- **传输速率相对低**：一般在几百 Kbps 到几十 Mbps。

- **传输延迟大**：受传输距离影响。

### 常用技术

- **公共交换电话网络（PSTN）**：利用传统电话线路传输数据，速率低，用于低速通信。

- **数字用户线路（DSL）**：借助普通电话线实现高速数据传输，有 ADSL、VDSL 等不同类型。

- **多协议标签交换（MPLS）**：通过添加标签实现数据包快速转发，常用于大型企业网络和运营商网络。
# 网络协议分类及简介

## 应用层协议
- **HTTP/HTTPS (HyperText Transfer Protocol / Secure):**  
  用于浏览网页，HTTPS 是 HTTP 的加密版本，使用 SSL/TLS 保证安全性。

- **FTP (File Transfer Protocol):**  
  文件传输协议，用于上传和下载文件，常用于服务器文件管理。

- **SMTP/POP3/IMAP (Simple Mail Transfer Protocol/Post Office Protocol/Internet Message Access Protocol):**  
  - SMTP：发送电子邮件。  
  - POP3 和 IMAP：接收电子邮件。

- **DNS (Domain Name System):**  
  将域名解析为 IP 地址，便于用户访问网站。

- **SSH (Secure Shell):**  
  远程登录协议，用于安全访问和管理远程服务器。

- **Telnet:**  
  用于远程登录，但不加密，安全性较低。

- **NTP (Network Time Protocol):**  
  时间同步协议，确保网络中设备时间一致。

- **SNMP (Simple Network Management Protocol):**  
  网络设备的管理和监控协议，例如路由器和交换机。

---

## 传输层协议
- **TCP (Transmission Control Protocol):**  
  面向连接的协议，提供可靠的数据传输。

- **UDP (User Datagram Protocol):**  
  无连接协议，速度快但不保证数据可靠性，常用于实时视频、语音通话等。

---

## 网络层协议
- **IP (Internet Protocol):**  
  提供数据包的寻址和路由功能，包括 IPv4 和 IPv6。

- **ICMP (Internet Control Message Protocol):**  
  用于网络诊断和控制（如 `ping` 命令）。

- **ARP (Address Resolution Protocol):**  
  将 IP 地址转换为物理 MAC 地址。

- **RARP (Reverse Address Resolution Protocol):**  
  将 MAC 地址转换为 IP 地址（较少使用）。

---

## 数据链路层协议
- **Ethernet (以太网协议):**  
  局域网的核心协议，用于设备间的数据传输。

- **PPP (Point-to-Point Protocol):**  
  用于点对点链路（如拨号连接）。

- **Wi-Fi (IEEE 802.11):**  
  无线局域网协议，用于设备之间的无线通信。

---

## 网络安全协议
- **SSL/TLS (Secure Sockets Layer / Transport Layer Security):**  
  加密网络通信协议，广泛应用于 HTTPS。

- **IPSec (Internet Protocol Security):**  
  提供网络层的加密和身份验证，常用于 VPN。

- **Kerberos:**  
  用于身份验证的安全协议。

---

## 路由和交换协议
- **BGP (Border Gateway Protocol):**  
  互联网路由协议，确保不同网络之间的通信。

- **OSPF (Open Shortest Path First):**  
  内部网关协议，计算最短路径。

- **RIP (Routing Information Protocol):**  
  早期动态路由协议，简单但效率较低。
# 名词解释

## SSID
- **定义**：服务集标识符（Service Set Identifier），无线网络的名称。
- **用途**：用于标识一个无线网络，用户连接无线网络时需要输入的名称。
- **特点**：
  - 可以是1到32个字符的任意文本，区分大小写。
  - 广播在无线信号中，可以被附近的设备看到。

## 网关
- **定义**：连接不同网络或子网，转发数据包的设备。
- **功能**：
  - 协议转换：将一种协议的数据包转换成另一种协议。
  - 地址转换：为数据包分配新的IP地址，如NAT。
  - 路由选择：决定数据包的最佳传输路径。
  - 安全控制：监控和控制数据流，防止未授权访问。
  - 数据压缩和解压缩：提高传输效率。
- **应用**：家庭网络中的路由器，企业网络中的防火墙、VPN网关等。

## 数据包
- **定义**：网络通信中传输数据的基本单位。
- **组成**：
  - 源地址和目的地址：标识发送方和接收方的网络地址。
  - 数据包头：包含元数据，如版本、端口、序列号、校验和等。
  - 数据负载：实际要传输的数据内容。
  - 校验和或CRC：用于错误检测。
  - 协议信息：指示数据包使用的协议。
- **传输**：遵循特定协议，如TCP/IP协议，涉及多个层次。

## 路由器
- **定义**：在不同网络或网络段之间转发数据包的网络设备。
- **主要功能**：
  - 路由选择：决定数据包从源头到目的地的最佳路径。
  - 网络连接：连接不同类型的网络，如局域网到广域网。
  - 数据包转发：根据目的地址将数据包发送到下一个路由器或目的地。
  - 网络地址转换（NAT）：<mark style="background: #FFF3A3A6;">允许多个设备共享一个公共IP地址访问互联网</mark>。
  - 防火墙功能：提供基本的网络安全。
  - 无线接入点：无线路由器允许无线设备连接网络。
  - 带宽管理：管理和优化网络资源。
  - VPN支持：支持虚拟私人网络连接。

# 完整解析地址 `http://localhost:5175/`

拆分三段：`http://` + `localhost` + `:5175` + `/`

## 1. `http://` 传输协议

代表使用 **HTTP 明文网络协议**，用于浏览器和本地服务之间传输网页、接口数据； 对比：`https://` 是加密协议，本地开发环境一般不用加密，直接 http。

## 2. `localhost` 本地主机域名

- 字面含义：**本地本机**，特指你当前运行浏览器的这台电脑；
- 底层对应IP：`127.0.0.1`（IPv4本地回环地址），所有操作系统默认绑定；
- 关键特性：
    1. 仅**本机自己**能访问，局域网其他手机、电脑无法打开这个地址；
    2. 不走真实网卡，只在电脑内部进程通信，不受防火墙、路由器拦截；
    3. 等价写法：`http://127.0.0.1:5175/`

## 3. `:5175` 端口号

### 端口作用

一台电脑同一时间可以跑 N 个服务，靠**端口号**区分不同程序：

- 80端口：默认网页端口（访问时可省略，如 `http://baidu.com`）
- 3306：MySQL数据库
- 22：SSH远程连接（CentOS7远程登录）
- 5173 / 5175：**Vite 前端开发服务器默认端口段**

### 5175 端口说明

主流前端构建工具 **Vite** 启动开发服务时，默认从5173开始分配端口：

- 5173 被占用 → 自动5174
- 5174 被占用 → 自动5175 说明你电脑上已经有其他Vite项目占用了5173、5174，当前这个前端项目自动顺延到5175端口。

## 4. 末尾 `/` 根路径

代表访问这个服务的**首页根目录**，省略写 `http://localhost:5175` 效果完全一致； 如果后面加页面/接口，比如 `http://localhost:5175/login`，就是访问登录页面。

# 整体含义翻译

**通过HTTP协议，访问本机电脑上运行在5175端口的前端开发服务首页**

# 补充实用知识点

## 1. 哪些场景会出现这个地址？

Vue3 / React / Svelte 项目，用 Vite 执行 `npm run dev` / `yarn dev` 启动本地调试服务器时，自动生成的访问地址。

## 2. 局域网其他设备如何访问？

localhost 仅限本机，想让手机/同局域网电脑打开页面：

1. 启动vite时指定开放0.0.0.0：

```
npm run dev -- --host
```

2. 访问地址替换为本机局域网IP，例如 `http://192.168.1.100:5175`

## 3. 和你之前 CentOS7 / VMware 的关联

如果你在VMware虚拟机CentOS7里跑前端服务：

- 虚拟机内访问：`http://localhost:5175`
- Windows宿主机访问虚拟机服务：需要填虚拟机IP + 端口（桥接/NAT模式放行端口）

## 4. 端口占用排查

如果5175端口打不开、提示端口被占用，Windows命令行查看占用进程：

```
netstat -ano | findstr :5175
```
