# 编程语言、编译器、解释器、环境

编程基础概念笔记

1. 解释型语言 vs 编译型语言

• 解释型语言：边翻译代码边执行，不生成独立机器码文件。例：Python、JavaScript。

• 编译型语言：先一次性将全部代码翻译成机器码文件，运行时直接执行机器码。例：C、C++。

• 半编译型语言：先编译为中间代码，运行时由虚拟机解释执行。例：Java、Dart。

2. 解释器 vs 编译器

• 共同点：都是“翻译官”，将源代码转为机器能懂的指令。

• 区别：

◦ 编译器：“整本翻译”，输出机器码文件，执行速度快。

◦ 解释器：“逐行翻译”，不生成机器码文件，执行时依赖解释器。

3. 环境（以Python为例）

• 全局环境：本地安装的完整运行环境，包含：核心解释器、包管理工具、默认库和用户安装的所有库，存储在本地磁盘。

• 虚拟环境：基于全局环境创建的“隔离小环境”，仅包含项目专属的库和配置，解释器“借用”全局环境的，用于隔离不同项目依赖。

关键联系

• 语言类型决定工具：解释型语言用解释器，编译型语言用编译器。

• 环境包含核心工具：Python环境包含解释器，C语言环境包含编译器及相关工具链。
# 同步、异步、并行、并发
|概念|描述|单核处理器实现方式|多核处理器实现方式|
|---|---|---|---|
|并发|一个宽泛概念，表示处理器能同时处理多个任务|通过分配时间片的方式，在多个任务间快速切换，从宏观上实现多个任务同时处理|一方面，不同任务可在不同核心上并行执行；另一方面，每个核心也可通过时间片轮转等方式并发执行多个任务|
