# 大语言模型训练核心逻辑笔记
## 一、核心底层认知：大模型本质
1. 大语言模型可以极简理解为**超级复杂的拟合函数**。
2. 给定输入 $X$（文本词元序列），模型计算输出 $Y$（下一个词元/概率分布）。
3. 全程训练目标：不断缩小「模型预测值」和「真实标准答案」的误差，完成函数拟合。

## 二、关键区分：预训练 vs 人工标注微调
### 1. 预训练阶段
- **无需大量人工手动标注**
- 数据源：全网书籍、文章、网页、文献、长文本等**天然原始文本**
- 核心模式：**自监督学习**，自己从文本中构造 X、Y，不靠人写答案

### 2. 人工标注阶段（微调 / 对齐）
- 需要人工手动制作数据
- 人工标注本质：手动构造高质量 **$(X,Y)$ 成对数据**
  - $X$：用户提问、对话上文、指令
  - $Y$：人工编写的标准优质回答、合规回复、打分标签
- 作用：修正预训练模型、提升对话能力、价值观对齐、规避风险

## 三、工程实操：预训练文本完整投喂流程
### 1. 原始文本存储格式
工程中常用轻量化、易批量处理格式：
- 基础：`.txt` 纯文本
- 工业主流：`JSONL`、Parquet 等结构化高效格式
- 内容：直接存放完整长文本、章节、段落，无人工加工

### 2. 文本预处理流水线
1. **清洗**：去乱码、广告、重复内容、违规文本
2. **分词 / 词元拆分（Tokenizer）**
   - 把连续文字拆成最小单元：词元（token）
   - 英文：子词、单词；中文：单字、常用词组
3. **映射编码**
   - 每个唯一词元对应一个固定数字 ID
   - 文字 → 数字序列 → 神经网络可识别的张量

### 3. 训练样本构造（核心）
1. 按模型上下文长度截断/拼接（如 1024 / 2048 个词元）
2. 不需要人手动写输入输出，**自动拆分 X 和 Y**

## 四、预训练自监督：X 与 Y 如何生成
### 方式1：因果语言建模（GPT 系列核心）
- 输入 $X$：**前 $n$ 个词元**
- 输出 $Y$：**第 $n+1$ 个真实词元**
- 逻辑：根据上文，预测下一个字/词，完美贴合日常续写、对话逻辑

### 方式2：掩码语言建模（BERT 系列核心）
- 随机把句子中部分词元盖住（掩码）
- 输入 $X$：完整序列（含掩码标记）
- 输出 $Y$：被遮挡位置的真实原词

## 五、串联总结（从基础神经网络到大模型）
1. 基础：神经网络 + 函数拟合 + 反向传播
2. 过渡：序列数据 → RNN/LSTM/GRU（解决时序依赖）
3. 进阶：注意力机制 → 自注意力
4. 成型：Transformer 架构 = 多头注意力 + 前馈网络
5. 落地：海量无标注文本预训练 + 少量人工标注微调
6. 最终：迭代拟合千亿级参数，形成具备理解、生成、推理能力的大模型
