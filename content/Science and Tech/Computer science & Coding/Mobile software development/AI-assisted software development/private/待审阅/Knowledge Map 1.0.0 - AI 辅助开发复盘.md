## 项目与复盘范围

Knowledge Map 是 Obsidian 插件，用嵌套圆展示文件夹、笔记和标题，支持布局调整及布局同步。本次总结主要覆盖后期工程加固、基线收敛、同步提示与跨端验收、限定性能优化、发布和开发材料归档。

这不是从第一行代码到发布的完整逐日历史。项目记录保留多个阶段状态；下文以对应阶段和最终结果区分。

## 1. 方向纠正：保留已经满意的同步体验

早期工程加固候选引入了手动分步引导，技术检查通过，但用户明确指出自己满意原有一键同步，主要需要提示文字更自然。

核对后发现当前工作区漏掉了更合适的后继功能线。后续以用户认可的体验作为约束，整合恢复能力和独立工程加固，避免丢失既有成果。

可学习：[[AI 开发技能 01 - 需求表达与验收标准]]、[[AI 开发技能 02 - 范围控制与分批推进]]、[[AI 开发技能 03 - Git 工作区与开发基线]]。

## 2. 文字评审：让用户看懂接下来会发生什么

用户反馈“相同建图范围”不够具体，共享图谱的一串标识需要说明是ID，审阅按钮也需要表达后续保存目标。文案修改围绕这些理解问题展开，并保留简洁界面。

“关闭→编辑→开启→审阅”的独立测试库体验中，用户检查了取消和确认的不同结果。产品判断由实际操作反馈补齐。

可学习：写出可观察的验收条件，并用用户的理解检验提示是否有效。

## 3. 跨端验收：最终一致之外，还要检查过程

PC 与 iPad 双向同步出现过成功，也出现过接收后画布未及时更新、需要重开标签的插曲。补充反馈让自动更新问题重新进入清单。

随后复现了范围外Markdown导致失效标记与重建调度不一致的缺陷。缺少首次异常的完整轨迹，因此保留了历史因果的不确定性。

复验中，沿用旧候选的 iPad 在编辑说明后又出现布局保存回弹。技术组合验证说明同一过期门禁也会影响保存；后续统一修复候选，再验证保存与已打开画布的接收更新。这一安排修正来自项目协作判断，不归责于用户操作。

可学习：[[AI 开发技能 04 - 审阅 AI 输出与验证证据]]、[[AI 开发技能 05 - 缺陷反馈与系统定位]]。

## 4. 性能调查：先分解，再做一批最小优化

G4 从历史证据和待决定事项出发，安排有界测量，再拆分宿主构造、历史校验和布局投影耗时。首批优化针对已有缓存中的重复读取。

固定样本的配对Node测量出现明确收益，并核对历史、快照、状态与输入保持。后续进行了受影响的原生和用户跨端短验。

结果没有扩大为所有历史规模、真实后端或移动端性能保证。

可学习：[[AI 开发技能 06 - 性能测量与最小优化]]。

## 5. 说明与发布：展示真实效果，交付确切文件

README布局动图按用户期望展示了把一个元素挤向其他元素、其他元素让开的效果。用户检查通过后，才固定相应展示资产。

发布准备核对了版本、检查、干净构建、打包、安装和远端字节。两位独立新用户试用没有完成，用户明确接受将其后置；该项始终没有记成已通过。

用户正式确认后，项目记录记载1.0.0的tag、GitHub Release和社区条目收尾完成。发布后的文件核对与目录状态分开记录。

执行中也出现过顺序失误：含机器路径的旧文档在复核结束前进入推送。后续做了普通脱敏修正及检查扩展，同时明确旧历史未被清除。

可学习：[[AI 开发技能 07 - 发布准备与交付核对]]。

## 6. 收尾归档：把下一次开工的现场保存下来

收尾覆盖Git之外的测试环境和资料。独有修改、必要状态、材料去向及恢复方法一起整理，旧工作树保留原位。

恢复演练与独立复核补出了外层忽略日志、空目录等遗漏。部分大型旧环境按路径和身份依赖原位登记，未创建重复全量镜像。

还记录了26个旧空文件的枚举/实际状态差异：所示mtime早于本轮，根因及早期正文未知。当前状态取得副本，并不代表恢复了未知历史内容。

可学习：[[AI 开发技能 08 - 可恢复归档与经验复用]]。

## 可以带到下次项目的做法

1. 把产品目标、保留行为和验收步骤写在实施之前。
2. 开工先核对来源和已有修改，复用合适的隔离工作区。
3. 分批推进，让技术结果与产品方向都能被检查。
4. 用户反馈记录额外干预；AI报告注明实际对象与验证层级。
5. 给缺陷和性能问题安排可解释的对照，保留失败证据。
6. 公开前完成确切差异与交付包审阅，发布后回读。
7. 用恢复演练检查归档，再将通用判断整理成笔记与skill。

## 仍需保留的边界

- Android、iPhone及所有设备/后端组合没有被本次证据覆盖。
- 独立新用户试用已后置；缺少这类易用性反馈。
- 静态检查和防漏守卫的实际范围有限。
- 固定样本优化没有证明大历史性能问题全面解决。
- 原位资料、未知旧内容和本机归档都有各自的恢复限制。
- 本套学习笔记尚待审阅，练习和个人掌握程度尚未验证。
