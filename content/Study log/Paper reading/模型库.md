# 模型库（读论文用的框架）

> 模型 = 我对"论文在干什么"的预设。==选哪个模型，决定我能看见什么、会漏掉什么==。所有模型都是压缩，包括主模型；模型库越厚，我看论文的眼睛越多，但也越容易先入为主。

## 快速选型（看到什么信号，用哪把刀）

| 论文里的信号 | 用哪个模型 | 我要盯的问题 |
|---|---|---|
| "以前的方法在 X 条件下失效" | 主模型：压缩试错 + 打补丁 | 它折叠了哪个自由度？边界在哪 |
| 引入新变量 / 新归一化 / 新曲线 | 辅 1：换坐标系 | 新尺子在真实取舍里怎么读 |
| 标题带 revisited / re-examining / limitations of | 辅 4：证伪 | 反例覆盖面多大 |
| 方法 = A 工具 + B 工具 | 辅 2：搭积木 | 拼起来有没有 1+1>2 |
| 全是实测/观测，没有设计空间 | 发现型（主模型失效） | 它看见了什么以前看不见的东西 |

---

## 主模型：论文 = 压缩试错（不变性）

- **一句话**：把一堆必须逐个试的自由度，折叠成一张能查的地图；折叠的算法是找到**不变性**。
- **它能看见**：设计空间里被折叠掉的维度；边界就是压缩比的对价；论文的品味体现在"我们不考虑…"。
- **它看不见**：发现型（先观测后解释）、纯理论（定义新对象）、证伪型（拆地图），以及论文的社会功能（抢优先权、申请经费）。
- **拆解时问**：它宣称什么无关？凭什么无关？这个无关性在什么条件下破？
- 详见 [[论文=压缩试错]]

## 辅模型 1：论文 = 换坐标系（新观测视角）

- **一句话**：不硬解旧问题，而是换一把尺子，让旧问题消失或被重述。
- **例子**：[[Silveira 1996 - gmID 方法]] 用 gm/ID 代替 Vgs−Vt——同一个晶体管，换成"跨导效率"这个坐标，中等反型区那些断掉的分段公式就不需要了。
- **识别信号**：新变量、新归一化、新的无量纲组合。
- **风险**：换了坐标系但没解决任何实际取舍——论文很漂亮，工程师不用。
- **问**：新尺子的刻度在真实取舍（增益/带宽/功耗）里怎么读？旧尺子到底在哪失效？

## 辅模型 2：论文 = 搭积木（组合创新）

- **一句话**：把别人两块现成的地图拼成一块新的。
- **识别信号**：combine / integrate / 联合优化。
- **风险**：增量灌水高发区。判断标准只有一条——拼出来的东西有没有出现 A、B 单独都不具备的性质（1+1>2）；只是"两个都用上"不算。
- **问**：单用 A 缺什么？单用 B 缺什么？拼起来补的恰好是这个缺口吗？

## 辅模型 3：论文 = 极限测试（打补丁）

- **一句话**：把已有地图推到极限条件，暴露失效，再局部修正。
- **识别信号**：under … conditions, the model degrades … we propose a correction。
- **价值**：边界本身就是贡献，工程界很吃这套（corner、短沟道、低压都是这个套路）。
- **风险**：补丁越打越多，地图退化成一堆 if 分支（L<…, V_DD<…, T>…）。这时候要回退问一句：==是不是坐标系选错了？== 那就要用辅模型 1 重读。
- **问**：这个补丁修的是"一处特例"，还是暴露了"整张图的坐标不对"？

## 辅模型 4：论文 = 证伪（拆地图）

- **一句话**：证明大家在用的某个先验是错的。
- **识别信号**：复现失败、大规模对照实验、理论反例、meta-analysis。
- **价值最高，数量最少**。读它只盯一件事：凭什么说别人错了（样本量、条件、统计口径）。
- **问**：反例的覆盖面是"某条件下失效"还是"整个框架错"？作者有没有把别人的条件设得比自己差？

## 反身一条

==模型库本身也是压缩==。遇到"这篇好像没什么可压缩的"，先怀疑是我的模型不够用（换一把刀），再怀疑论文是水的。反过来，用主模型读所有论文，会让我只会欣赏"造地图"的论文，把真正重要的发现型工作当成"没方法"。
