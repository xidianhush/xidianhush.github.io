# Part A · 人怎么复用（一周的节奏）

## A0 每个文件的角色（不要拿错）

| 文件 | 它的角色 | 我的动作 |
|---|---|---|
| [[论文卡模板]] · [[感悟卡模板]] | 模具 | 复制，不读 |
| [[AI 拆解指令]] | 给 AI 的话术 | 复制粘贴，不读 |
| [[Paper reading]]（hub） | 地图与索引 | 每周五扫一眼 |
| [[模型库]] | 刀的目录 | 读不下去时翻 |

## A1 怎么插入模板（两种，都能用）

**方法一（推荐，已配置好）**
`Ctrl/Cmd + P` → 输入 `insert template` / `插入模板` → 选「论文卡模板」。
- 模板文件夹已配置为 `Logs/Study log/Paper reading/模板`；
- 模板里的 `{{title}}` 会自动变成当前笔记名，`{{date:YYYY-MM-DD}}` 会变成今天；
- 所以流程是：**先**新建笔记并命名成 `第一作者 年份 - 关键词`，**再**插入模板。

**方法二（手动）**
打开模板 → 全选复制 → 新建笔记粘贴。缺点：`{{title}}`、`{{date}}` 不会被替换，要自己填（模板里其他 `{{...}}` 都是给你手写的提示语，本来就不会自动填）。

## A2 一篇论文的 40 分钟（照着做就行）

1. **新建**：`Papers/第一作者 年份 - 关键词` → 插入论文卡模板。
2. **先猜 1 分钟**：只看标题和一张图，在"我读它的理由"后面写一句"我猜它靠 ___ 压缩"。==猜错没关系，这一步是在激活自己已有的地图。==
3. **AI 铺路 10 分钟**：把 PDF + [[AI 拆解指令]] A 段丢给 AI。等它输出的同时，自己读 intro 最后两段（"以前为什么不行"就在那儿）。
4. **自己核 20 分钟**：AI 草稿里只信带图/表号的部分；每条数字回原文核一次，核不了就写「待核」。这一步不能省，==省了这套系统就退化成 AI 读论文、我存摘要==。
5. **写边界 5 分钟**：第 5 节至少 3 条，其中 1 条作者没承认、我从实验条件反推出来的。
6. **写第 6 节 3 分钟**：「如果没这篇文章我会怎么走」。这节 AI 写不了，它是整套系统的核心。
7. **抽感悟 5 分钟**：只问"这条能搬到别的论文/别的方向吗"。能 → [[感悟卡模板]] 另起一卡；不能 → 不写。
8. **加选题 1 分钟**：[[选题池 - 地图外第一格]] +1 行。
9. **更新索引 30 秒**：[[Paper reading]] 里加一行。

## A3 什么时候**不要**建卡（防止系统变成负担）

| 情况 | 怎么做 |
|---|---|
| 只想确认"这方向有没有人做过" | 读摘要 + 结论，不建卡；一行记进选题池候选区或 [[Inspirations & Lessons]] |
| 综述 / survey | 建"地图卡"（一张卡收 5–10 篇），不是单篇论文卡 |
| 读不下去 | 说明缺前置知识，先回 [[Analog IC]] 补那一章；硬读只产出自责 |
| 论文太烂 | 读 10 分钟，一句话记进 card 也无妨，然后弃。==判断"烂"本身就训练品味== |

## A4 卡住时的自救表

| 症状 | 处理 |
|---|---|
| 三行卡第一行写不出 | 找不到不变性 → 这篇可能是搭积木/打补丁型，换 [[模型库]] 的辅模型重读 |
| 边界只能写一条 | 边界藏在实验条件里：工艺、L、V_DD、温度、负载、频段。逐项问"换掉会怎样" |
| 感悟写了三条以上 | 砍到两条。多出来的不是感悟，是笔记 |
| 一周一篇都没读完 | 降到"只读 intro + 一张图"，写半张卡也算完成 |
| 觉得自己在抄 AI 的话 | 做 [[AI 拆解指令]] D 段"审稿人模式"，让它指出哪句是转述 |

## A5 三个复盘节点

- **每周五 15 分钟**：hub 里的 checklist。
- **每 5 张卡**：横向对比——5 张卡的三行卡并排看，如果某几张的"不变性"是同一句话，说明它们是同一张地图的分支，可以合并成一篇"路线笔记"。
- **每 20 张卡**：回看 [[模型库]]，加一把刀或合掉一把。

# Part B · 让 AI Agent 读这套技能（按我的实际客户端排序）

> 目标客户端：**DeepSeek Harness（DSH）+ Codex**。Copilot 用得少，放附录。
> 总原则：==客户端有文件读写能力时，只给路径，不给提示词==。提示词是写给"看不见我 vault 的 AI"的，不是写给我的 agent 的。

## B1 关键机制：目录级 `AGENTS.md`（DSH 与 Codex 都支持）

本目录下有一个 `AGENTS.md`，它就是 agent 的入口协议：何时适用、先读哪 6 个文件、你负责什么、硬约束、交付验收。

- **Codex**：`AGENTS.md` 按目录层级加载（root → 子目录）。在 `Logs/Study log/Paper reading` 或其子目录里工作时自动生效，不需要任何配置。
- **DSH**：同样机制。==实测：这份文件写完的下一轮，系统提示里就自动出现了"Additional instructions from: Logs\Study log\Paper reading\AGENTS.md"==。

所以：**协议正文只写一遍**（在 `AGENTS.md` + 各笔记里），不给每个客户端复制一份。

## B2 DSH（我主要用它）

新开一个会话，working directory 指到 vault（或任何地方），然后说一句人话：

```
按 Paper reading 协议读这篇：D:\path\to\paper.pdf
```

- DSH 会自己去读 `AGENTS.md` → 再读那 6 个文件 → 落卡到 `Papers/`、往 [[队列与待核]] 追加待核项、更新索引。
- **已装成个人 skill（2026-11-19）**：`~/.agents/skills/paper-reading/SKILL.md`，所以==在任何目录开 DSH 会话，说"读这篇论文"它都能自己想起来==，不依赖当前工作目录。
- 改了 vault 里那份 `copilot/skills/paper-reading/SKILL.md` 之后，同步一次即可：

```powershell
Copy-Item "D:\obsidian_vault\hush-ob-bucket\copilot\skills\paper-reading\SKILL.md" "$env:USERPROFILE\.agents\skills\paper-reading\SKILL.md" -Force
```

> 分工：vault 里那份是**源**（跟着 git 走，换机器不丢），`~/.agents/skills` 里那份是**安装副本**。只改源、改了才同步，两份就永远一致。==`SKILL.md` 只写"去哪找材料"，协议正文永远只有一份（`AGENTS.md`）==。

## B3 Codex（我另一主力）

- 直接在 vault 里开 Codex，工作目录落在 `Logs/Study log/Paper reading/`（或者 `Papers/` 下新建文件时天然就在子目录），`AGENTS.md` 自动加载。
- 触发句同上，一句话即可；Codex 有文件读写，会自己落盘。
- 如果 Codex 会话是从 vault 根目录开的，它只会读根 `AGENTS.md`；这时多打一句 `见 Logs\Study log\Paper reading\AGENTS.md` 即可。
- 跨项目触发同样走个人 skill（`~/.agents/skills` 是 Codex 的个人技能目录，已装，无需再跑命令）。

## B4 没有文件权限的聊天 AI（ChatGPT / DeepSeek 网页版）

只有这一层需要"贴提示词"：把 [[AI 拆解指令]] 的 **A 段** + PDF 正文贴进去；或用 Part C 的固定开场白。

## B5 Copilot（用得少，保留但不维护）

- 自定义 prompt：`copilot/copilot-custom-prompts/论文拆解 - 四问 + 三行卡.md`，`Ctrl/Cmd+P` → 搜「论文拆解」。
- `@` 引用笔记：`@论文=压缩试错 @模型库 @论文卡模板` + 论文内容，效果依然最好（AI 读到的是我的判断）。
- 这两样哪天不想要了，直接删，不影响 DSH / Codex 那条主线。

## B6 我平时要说的几句话（记这五句就够）

| 我想做的事 | 说这句 |
|---|---|
| 读一篇新论文 | `按 Paper reading 协议读这篇：<路径或 DOI>` |
| 让 AI 先排个队 | `把这批论文按"值不值得读"排队，理由给一句` |
| 清账 | `汇总 队列与待核.md 里的待我核，按论文卡分组` |
| 找选题 | `只看这张卡的第 5 节，给 3 个地图外第一格` |
| 复盘 | `把 Papers/ 里的三行卡并排看，哪些是同一张地图的分支？` |

# Part C · 给任何 AI 的固定开场白（复制即用）

```
我在 Obsidian 里维护一套论文阅读系统，路径 Logs/Study log/Paper reading/。
开始前先读：模型库.md、Insights/论文=压缩试错.md、模板/论文卡模板.md、AI 拆解指令.md。
然后按 AI 拆解指令的 A 段（四问 + 6 条硬约束）拆这篇论文，输出论文卡 Markdown。
我的方向：模拟 IC 晶体管尺寸设计。
不要写摘要，不要夸奖，不确定就写"不确定"，没有不变性就说"没有"。
```
