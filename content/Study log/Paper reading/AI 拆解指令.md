# AI 拆解指令（Prompt）

> 用法：读一篇论文时开三件事——① 下面 A 段 + 论文丢给任意 AI；② 在 Obsidian Copilot / Smart Composer 里用 B 段（带 @ 引用我自己的笔记）；③ 自己读原文，只用 C 段追问去核对 AI 的说法。
> 核心原则：==AI 负责铺满四问，我负责核证据和画边界==。AI 的输出永远是草稿，进卡之前必须过我一遍。

---

## A. 通用指令（复制给任何 AI，后面附 PDF 或全文链接）

```
我的研究方向是模拟 IC（晶体管尺寸设计）。读论文的目标不是做综述，是给自己的搜索装地图。请按下面四问拆解，输出用我的论文卡 Markdown 格式，我要直接粘进 Obsidian。

【四问】
1. 目标：这篇真正优化的指标是什么？它是哪个物理量的代理指标？（有没有 Goodhart 风险：把 Proxy 当成 Goal）
2. 旧地图失效：以前的方法默认了什么前提？在什么条件下崩？崩的代价用数字说（面积/功耗/迭代轮数）。
3. 新坐标系：作者引入什么新变量、新归一化曲线或新表来压缩搜索？请明确指出一个"不变性"——他说哪个量与哪个设计自由度无关，凭什么无关。
4. 边界与未探索：适用域、误差、被忽略的效应；再指出边界外最近的一个未覆盖格子。

【硬约束】
- 禁止"本文提出了一种…取得了良好效果"式转述。每一句要么是作者的判断（标 Fig./Table/页码），要么是你基于条件的推断（前面写"推断："）。
- 所有数字必须带出处和条件（工艺、L、V_DD、温度）。原文没给就写"原文未给"，不要补一个看起来合理的数。
- 第 3 问找不到不变性就直说找不到，不要凑。很多论文确实只是搭积木或打补丁。
- 第 4 问至少给 3 条边界，其中至少 1 条是作者没有承认、你从实验条件反推出来的。
- 最后给 3 条"地图外第一格"候选，每条写成一句可做的问题，并标注它属于哪类缺口（拓扑 / 工艺迁移 / 变异与可靠性 / 版图后 / 工具自动化），以及"可能已经有人做过"的概率（高/中/低）和理由。
- 每节结尾标一句"不确定项"：你推测但没证据的地方。不要编。

【输出格式】
按我的论文卡模板 0–8 节输出，第 0 节"三行卡"放最前面（它凭什么压缩 / 代价 / 地图外第一格），然后 1 元信息、2 旧地图失效、3 新地图与不变性、4 证据表（表格：主张｜证据与条件｜我是否复核）、5 边界（作者承认 / 推断 / 待验证）、6 如果没这篇文章我会怎么走、7 我的一手感悟（留空给我写）、8 钩子（可执行任务勾选清单）。
```

---

## B. 在 Obsidian 里用（Copilot / Smart Composer，带我的笔记当上下文）

在对话里引用这几篇，再贴 A 段的四问与硬约束（不必重贴格式部分）：

```
@论文=压缩试错 @模型库 @论文卡模板 @Silveira 1996 - gmID 方法
```
（最后一个换成"最近一篇同类论文"当风格样例，让 AI 对齐我的卡片口吻。）

如果插件读不到 PDF：只把 **abstract + intro 最后两段 + 每张图的 caption + 结论** 贴给它，够跑完四问。全文灌进去反而会让它写摘要。

---

## C. 追问清单（AI 的话不能全信，用这几句怼）

1. 你说的这个"不变性"，在原文哪张图上验证的？图里换了几组什么参数？只有一组就不算。
2. 作者做了哪些对照实验？**没做的对照**是哪几个？
3. 如果把这套方法搬到我这条工艺（___ nm，V_DD=___），哪一步最先失效？给条件，不要给"可能需要修正"。
4. 这篇和它引用的 [关键前作] 相比，增量是"压缩了一个维度"还是"打了一个补丁"？
5. 以这篇为基线，审稿人最容易攻击的三个点是什么？
6. 作者没写出来、但一定存在的假设是哪三条？
7. 这篇的结论在什么条件下会反过来？

## D. 审稿人模式（读完自己写完卡之后，最后跑一次）

```
以下是我写的论文卡（贴在下面）。你是审稿人，只做三件事，不要夸我：
1. 指出哪几句是"转述原文"而不是我自己的判断；
2. 指出哪些边界缺数字或条件；
3. 指出我"地图外第一格"里最可能已经被做过的那一条，并说明大概会以什么关键词存在。
```
作用：==防止把 AI 的转述当成自己的理解==。一周跑一次就够。

---

## E. 制图模式（每月一次，用来找方向）

```
给我「模拟 IC 晶体管尺寸设计」方向近 10 年的 5 条主要技术路线。每条一句话：它压缩了哪个维度、它的边界在哪、它现在被谁接手（工具/论文/工业实践）。最后指出这 5 条路线之间还没被填的空白格，按"一个学期内可验证"排序。
```
输出直接进 [[选题池 - 地图外第一格]] 的候选区，然后逐条检索确认是否已被做过。

---

## F. 使用纪律

- [ ] AI 给的数字，进卡前必须我自己在原文/图表里核一次；核不了就写"待核"。
- [ ] AI 写的"地图外第一格"，我至少否掉一条（否则等于没想）。
- [ ] 一次对话只处理一篇论文，不要混读。
- [ ] 每张卡最后必须有一句"如果没这篇文章我会怎么走"，这句 AI 写不了，只有我能写。
